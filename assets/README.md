# Generated diagram assets

`workflow.html`, `workflow.svg`, `workflow.zh.html` and `workflow.zh.svg` are generated. Edit the
candidates — `workflow.archify.json` and `workflow.zh.archify.json` — never the rendered files.

The generator is the external Archify CLI (v3.2.0 at the last render), not a repository script, so
this page is the only regeneration path and it is manual:

```bash
archify finalize workflow assets/workflow.archify.json    assets/workflow.html    --quality showcase --json --out-dir .archify/<folder>/review-N
archify finalize workflow assets/workflow.zh.archify.json assets/workflow.zh.html --quality showcase --json --out-dir .archify/<folder>/review-N
```

Use a fresh `--out-dir` per run: an existing evidence directory refuses the second finalize. The
rendered pages then need hand post-processing, which the generator has no flag for:

1. Replace the `<desc id="archify-diagram-description">` body with the delivery-order sentence
   (EN and ZH respectively) — the default is "A workflow diagram generated by Archify.".
2. Delete the `<a class="diagram-guide-credit">…</a>` promotional "star on GitHub" block and the
   `viewer.guide.credit` / `viewer.guide.star` entries in the `<script id="archify-i18n-data">`
   payload. Attribution stays in the embedded `archify-software-notices` metadata the generator
   requires; the credit block itself does not belong in this repository's pages.
3. Build the standalone SVG from the page: take its `<svg>…</svg>`, prepend
   `xmlns="http://www.w3.org/2000/svg"` and `xmlns:xlink="http://www.w3.org/1999/xlink"` to the
   root, insert one `<style><![CDATA[…]]></style>` holding the page-level stylesheets joined in
   page order, and strip `tabindex`, `role`, `aria-pressed` and the `aria-label="Focus …"` values
   from node `<g>` elements. Those attributes drive the interactive viewer only, which the static
   export has no script for; `<title>`, `<text>`, `data-*` and the root `role="img"` stay.
4. Verify both SVGs parse:
   `python3 -c "import xml.etree.ElementTree as ET; [ET.parse(p) for p in ['assets/workflow.svg','assets/workflow.zh.svg']]; print('ok')"`

Re-rendering also rewrites `assets/*.delivery.json` (git-ignored) and `.archify/`; neither is
committed, and a stale delivery receipt makes `archify check` report a provenance mismatch — delete
it and re-run the finalize.

## Manual sync obligation

Editing a candidate without re-running the pipeline above leaves `README.md`'s `<img>` and the
committed pages showing the previous render. No automatic check catches that yet: drift-lint only
reads these files for retired stage names, never for candidate/artifact agreement. Re-render both
locales whenever a candidate changes.
