- Added **`mstar path check [path]`**: read-only path-ownership check over two domains (exit `0` clean, `1` findings). **Process** state (`{PLAN_DIR}`, `{SDD_DIR}`, `{ITERATION_DIR}`, `{WORKFLOW_DIR}`, `{PROJECT_DIR}`, `{REVIEW_DIR}`, `store.db`) must be git-ignored inside the control checkout (`path.process-outside-control`). **Tracked** results (`specs`, `knowledge`, `adr`) must not be git-ignored (`path.result-ignored` — that content can never be committed or shared) and must sit in the caller's own checkout, so a linked worktree cannot write them into the control checkout (`path.result-outside-worktree`). A git probe that cannot answer reports `path.unverifiable` instead of passing silently. With no argument the envelope reports `trackedHarness` and `processHarness` separately; with a `path` it probes that one target under the same two rules.
- **engine**: `resolveSpecsDir` gains `.agents/specs` between the harness dir and `docs/specs` (the full chain is now `.mstarc` `specs_dir` → `{HARNESS_DIR}/specs` → `.agents/specs` → `docs/specs` → root `specs` → legacy `designs`); `resolveKnowledgeDir` gains an `.agents/knowledge` candidate; new `resolveAdrDir` resolves `.mstarc` `adr_dir` → `{HARNESS_DIR}/adr` → `.agents/adr` → `docs/adr`. `.mstarc` gains the `adr_dir` key (`MstarcStringKey` `adrDir`). A repo whose `.mstar/` is gitignored wholesale can now resolve its tracked results under `.agents/`. The canonical `.gitignore` snippets re-include `adr/` symmetrically with specs and knowledge (`!.mstar/adr/` + `!.mstar/adr/**`, and the `.agents` pair), so a scaffolded repo can commit ADRs; an author-declared `.gitignore` is still left untouched.
- **cli**: `mstar path resolve` prints `knowledgeDir` and `adrDir` alongside the existing dirs.
- Updated `mstar-conventions` (`{ADR_DIR}` symbol, the `.mstarc` `adr_dir` key, the specs/knowledge/adr resolution chains, the fully-gitignored `.agents/` rule and `mstar path check`), its `references/artifact-storage-paths.md`, `mstar-use-cli/references/checks-and-lints.md`, `mstar-artifacts/references/knowledge-and-designs.md`, and `docs/runtime-reference.md`.

- **cli**：`mstar path resolve` 输出新增 `knowledgeDir` 与 `adrDir`。
