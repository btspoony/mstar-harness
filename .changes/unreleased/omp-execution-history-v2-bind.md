category: Changed

- The OMP hidden-history reader now decodes the **version-2 phase-2 `bind`** the active producer writes (`{version: 2, kind: "bind", hostSessionId, workflowId, executionBinding}`). The restore-guard mirror branches on `payload.version` first: generation 2 requires non-empty `hostSessionId`/`workflowId` plus a **shape-only presence check** of `executionBinding` (an object with `version: 1`, a non-empty `harnessRoot`, and a `session` object whose `storeId`, `sessionId` and `workflowId` are non-empty strings, whose `role` is `coordinator | plan-pm`, whose `planId` is `null | string` and whose `epoch` is a positive safe integer). Nothing beyond that shape is examined: no store id, epoch or session value is interpreted, resolved, compared or projected — the reference is a lookup the record carries, never authority.
- The view gains exactly **one nullable field**, `executionBinding` (`harnessRoot`, `storeId`, `epoch`, `sessionId`, `role`, `planId`), populated only for a verified version-2 `bind`, whose view reports `generation: 2`. A version-2 record carries no envelope provenance, and no credential, token, path or session-file field is added anywhere.
- Generation `2` is admitted for `kind: "bind"` **alone**; every other hidden type and phase-2 kind still decodes under generation `1` and nothing else, and any other declared version is refused exactly as before. Legacy `version: 1` decoding, its guard and its view are unchanged, and a version-2 `bind` whose `executionBinding` is missing or malformed is diagnosed `payload-record-invalid` with its payload retained in full.

- OMP hidden-history 读取模块现在可解码 active producer 写入的**version-2 phase-2 `bind`**（`{version: 2, kind: "bind", hostSessionId, workflowId, executionBinding}`）：restore guard 镜像先按 `payload.version` 分支——generation 2 要求非空 `hostSessionId`/`workflowId`，并对 `executionBinding` 做**仅形状的存在性检查**（对象 `version: 1`、非空 `harnessRoot`，且 `session` 对象的 `storeId`/`sessionId`/`workflowId` 为非空字符串、`role` 为 `coordinator | plan-pm`、`planId` 为 `null | string`、`epoch` 为正的安全整数）。除形状外一律不检查：绝不解释、解析、比较或投影任何 store/epoch/session 值——该引用只是记录携带的查找信息，从不是权威。
- view 仅新增**一个可空字段** `executionBinding`（`harnessRoot`、`storeId`、`epoch`、`sessionId`、`role`、`planId`），只在已核验的 version-2 `bind` 上填充，其 view 报告 `generation: 2`。version-2 记录不携带 envelope provenance，且任何地方都不新增 credential、token、path 或 session-file 字段。
- generation `2` **仅**对 `kind: "bind"` 开放；其他 hidden 类型与 phase-2 kind 仍只在 generation `1` 下解码，其他任何声明版本照旧被拒绝。legacy `version: 1` 的解码、guard 与 view 保持不变；`executionBinding` 缺失或形状错误的 version-2 `bind` 被诊断为 `payload-record-invalid`，其 payload 完整保留。
