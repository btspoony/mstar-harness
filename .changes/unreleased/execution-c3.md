- Added the **populated version-2 execution manifest** (`packages/engine/src/execution-migrate.ts`): it records the canonical configured roots, every discovered surface identity with the exact source-witness set assigned to that `(surface, workflowId)`, the row's evidence documents and — where the contract requires one — C3's consumer/host discovery proof, all under one content hash. `previewExecutionMigration` takes the explicit inventory path; the discovery classifies registered, terminal/unregistered and deferred content without ever scanning a home directory or a credential store.
- Added **`collectExecutionCoverage`** and the boundary revalidations: `applyExecutionMigration` requires the validated `coverage` (recomputed from the same bytes under the maintenance → root → workflow locks and persisted in the new `coverage_json` column), `activateExecutionMigration` requires `coverageDigest` (recomputed, compared with the staged record and recorded in the activation receipt) and `retireExecutionSources` revalidates the recorded coverage digest before moving anything. The "a populated surface blocks activation" rule is replaced by validated coverage.
- Added the **host-session and consumer discovery proofs**: the `omp-hidden-entries` row is built from the explicit per-workflow native-session inventory with one envelope per declared session and the pinned operator attestation's stopped/reloaded coverage, and the consumer rows derive their tree/copy closures from real bytes with R1's own rule (`{path, kind, sha256, linkTarget}` entries, links recorded by their tree-relative target and resolved bytes, generated trees skipping the producer's own manifest basename). A consumer manifest that the reviewed substrate cannot decode (an aggregate producer artifact, or a non-canonical encoding) is refused with a message naming the cross-package conflict instead of being reformatted.
- Extended **retirement** to session envelopes: the per-item ledger now archives the core root/snapshot sources plus the envelope rows validated `retire` (historical bodies with no recorded binding), under the same exact-hash, destination and conflict rules. Terminal workflow dirs are imported as history without root-registry membership, and P4's immutable `identity_recoveries` audit is preserved in the imported workflow state as provenance.
- Discovery now **refuses a present `agent-flow-compaction.json`** before any receipt or staging step, and classifies the agent-flow identity index and sealed history chunks as part of the retained ledger surface.
- Exported the C2 coverage substrate and the F1 retained-notes API from the engine barrel.

- 新增 **v2 填充式执行 manifest**（`packages/engine/src/execution-migrate.ts`）：在同一个内容哈希下记录规范化配置根、每个已发现 surface 身份及其 `(surface, workflowId)` 精确 source witness 集合、该行的 evidence 文档，以及契约要求的 C3 consumer/host discovery proof。`previewExecutionMigration` 接收显式 inventory 路径；discovery 会分类已注册、终态/未注册与 deferred 内容，且从不扫描用户主目录或凭据存储。
- 新增 **`collectExecutionCoverage`** 与各边界重验：`applyExecutionMigration` 要求已验证的 `coverage`（在 maintenance → root → workflow 锁下由同一批字节重算，并写入新增的 `coverage_json` 列），`activateExecutionMigration` 要求 `coverageDigest`（重算、与 staged 记录比对并记入 activation receipt），`retireExecutionSources` 在移动任何文件前重验已记录的 coverage 摘要。“已填充 surface 即阻塞激活”被已验证覆盖取代。
- 新增 **host-session 与 consumer discovery proof**：`omp-hidden-entries` 行由显式 per-workflow 原生会话清单构建（每个声明的会话一个 envelope），并要求被 pin 的 operator attestation 记录 stopped/reloaded 覆盖；consumer 行按 R1 自身规则从真实字节推导 tree/copy 闭包（`{path, kind, sha256, linkTarget}` 条目，symlink 记录其 tree 相对目标与解析后字节，generated tree 跳过 producer 自身 manifest 文件名）。评审基底无法解码的 consumer manifest（聚合产物或非规范编码）会以点名跨包冲突的消息拒绝，而不会被改写重排。
- **退休**扩展至 session envelope：逐项 ledger 现在归档核心 root/snapshot 来源，以及被校验为 `retire` 的 envelope 行（无绑定记录的历史正文），并沿用完全一致的哈希、目标与冲突规则。终态 workflow 目录作为历史导入且不获得根注册成员资格，P4 不可变 `identity_recoveries` 审计作为出处保留在导入的 workflow 状态中。
- discovery 现在会在任何 receipt 或 staging 之前**拒绝存在的 `agent-flow-compaction.json`**，并将 agent-flow 身份索引与封存历史 chunk 归类为留存 ledger surface 的一部分。
- 在 engine barrel 中导出 C2 覆盖基底与 F1 留存 notes API。
