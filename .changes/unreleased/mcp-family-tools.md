---
category: Changed
packages: cli
---

- **The MCP server publishes one tool per command family instead of one per command.** `tools/list` was the largest fixed cost of every agent session: 113 tools and 173,340 characters of description + input schema (189,881 for the payload-composed input view), 66% of that description text being a `CLI: mstar … --flags` usage line a tool caller cannot run. Each family now publishes one `mstar_<family>` tool with a required `action` selecting a real command, a merged field set derived from the command descriptors, and a compact description (purpose, one line of required fields per action, the `<family>.<action>` id shape `mstar_schema` accepts, and a payload pointer where the action has one). Measured on the same probe: 113 tools → 33, description + input schema 173,340 → 31,209 characters. Output schemas are no longer published (154,471 → 0), so the old publication was 327,811 characters including them (~91k tokens) against 31,209 today (~8.7k tokens).
- **Admission is unchanged.** Every call still resolves to its command's own descriptor and composed schema, so validation strictness, aggregated refusals, `defaultSessionId`/`defaultHarness` handling and the identity lock behave exactly as before; an unknown `action` refuses with the family's real action list plus the recovery, and a session selector supplied to an action that does not declare one refuses before admission naming the actions that accept it (instead of being silently dropped by that action's schema). `mstar_schema` remains the field-detail authority, and `renderCommandContract` no longer spends MCP description budget on CLI usage syntax.

- **MCP 服务器改为每个命令家族发布一个工具。** `tools/list` 是每个 agent 会话最大的固定成本：113 个工具、173,340 字符的描述与输入 schema（按 payload 组合视图计为 189,881 字符），其中 66% 的描述文本是工具调用方无法执行的 `CLI: mstar … --flags` 用法行。现在每个家族只发布一个 `mstar_<family>` 工具，必填 `action` 选择真实命令，字段集由命令描述符合并推导，描述保持紧凑（家族用途、每个 action 一行的必填字段、`mstar_schema` 接受的 `<family>.<action>` id 形状，以及带 payload 的 action 的指针）。同一探针实测：113 → 33 个工具，描述与输入 schema 173,340 → 31,209 字符。输出 schema 不再发布（154,471 → 0），因此含输出 schema 的旧发布负载为 327,811 字符（约 91k token），今天是 31,209 字符（约 8.7k token）。
- **准入语义不变。** 每次调用仍解析到该命令自身的描述符与组合 schema，校验严格度、聚合拒绝、`defaultSessionId`/`defaultHarness` 处理与身份锁与之前完全一致；未知 `action` 会带家族真实 action 列表与恢复路径拒绝；把 session 选择器传给不声明它的 action 时，会在准入前拒绝并点名接受该选择器的 action（而不是被该 action 的 schema 静默丢弃）。`mstar_schema` 仍是字段细节权威，`renderCommandContract` 不再把 CLI 用法语法计入 MCP 描述预算。
