- Added two vocabulary entries to `CONCEPTS.md` from the execution-authority cutover iteration (2b) compound round: **Consulted header set** (a label-keyed plan-Markdown parser consults a closed, exactly-matched label set — never a prefix, so a descriptive sibling like `Working branch policy` cannot alias a consulted field) and **Maintenance exclusion** (the single outermost lock an engine lifecycle operation holds so no cooperative writer in any package can append into its window; a coordination discipline, not an authority).
