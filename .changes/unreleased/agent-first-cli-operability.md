- **Agent-first CLI operability (#393):** `--help`, `schema`, and admission now derive from one shared registry contract (118 commands observed in the runtime `tools/list`); missing input produces one aggregated refusal listing every missing field (path/code/expected/received), the minimal required set, safe defaults, conditional/alternative facts, `helpRoute`, and `recovery` on both CLI and MCP.
- **Error fidelity (touched families: session, milestone, pr-review, audit, dashboard, status, workflow):** engine-authored `code`/`message`/`details` travel verbatim on the refusal paths this plan touched. Malformed attestation/proof/evidence/policy causes are sanitized: real parser grammar and the parser-reported location survive while submitted operands and secret-shaped values are withheld — verified per runtime with actual Bun 1.4.0 and Node 24 malformed inputs, not universally. Schema-unsupported refusals report highest applied schema, supported maximum, and first unsupported migration as three distinct machine facts.
- **Public operations:** `workflow-note.append`/`workflow-note.coverage` join the canonical registry on CLI and MCP; an ambient `MSTAR_HOST_SESSION_ID` or launcher-minted identity satisfies the caller-context requirement without `--session-id` (verified on the built bundle), explicit selectors keep precedence, and no-identity/malformed selectors refuse without writing. `issue.*` mutations publish numeric revision CAS, refuse blank replay ids, and return the generated id in the receipt. `workflow.evidence` publishes the per-delivery-kind file-content contract with record-time revisability and close-time freeze.
- **Terminal recovery & native coordinator:** `workflow.adopt-terminal` settles terminal-unregistered ACTIVE sessions via optional operator attestation with addressed-target completeness and per-operation file recovery (POSIX error codes retained); read-only store opens converge across the Bun writer-close window (bounded retry, persistent corruption still refused). The registered `mstar_coordinator` contract binds/recovers ACTIVE schema-9 authorities with host-derived identity, aggregate refusals, and real loaded-entry provenance — evidenced on the SDK 18.3 adapter route only; it does not replace a running host's cached registration, and the guidance no longer promises reload-style replacement.

- **Agent 优先的 CLI 可操作性（#393）：** `--help`、`schema` 与准入校验统一由共享注册契约派生（运行时 `tools/list` 实测 118 个命令）；缺失输入以单次聚合拒绝呈现全部缺失字段（path/code/expected/received）、最小必填集、安全默认、条件/备选事实、`helpRoute` 与 `recovery`，CLI 与 MCP 一致。
- **错误保真（本计划触及的族：session、milestone、pr-review、audit、dashboard、status、workflow）：** 本计划触及的拒绝路径上引擎创作的 `code`/`message`/`details` 原样透传。畸形 attestation/proof/evidence/policy 的解析原因经过消毒：真实解析器语法与解析器上报位置保留，提交的操作数与秘密形状内容被隐藏——以真实 Bun 1.4.0 与 Node 24 畸形输入按运行时分别验证，非普遍声明。schema 不兼容拒绝以三个独立机器事实报告最高已应用 schema、支持上限与首个未知 migration。
- **公共操作：** `workflow-note.append`/`workflow-note.coverage` 以 CLI 与 MCP 进入规范注册表；环境 `MSTAR_HOST_SESSION_ID` 或 launcher-minted 身份可在不带 `--session-id` 时满足调用者上下文要求（built bundle 实测），显式选择器优先级保留，无身份/畸形选择器拒绝且不写入。`issue.*` 变更发布数字版本 CAS、拒绝空白 replay id、并在回执返回生成 id。`workflow.evidence` 发布按交付类型的文件内容契约，保留记录时可修订与关闭时冻结。
- **终态恢复与 native coordinator：** `workflow.adopt-terminal` 通过可选操作者证明结算终态未登记的 ACTIVE 会话，要求目标完备并按操作保留文件恢复指引（保留 POSIX 错误码）；只读 store 打开可跨越 Bun writer 关闭窗口收敛（有界重试，持久损坏仍拒绝）。注册的 `mstar_coordinator` 契约以宿主派生身份绑定/恢复 ACTIVE schema-9 权威，聚合拒绝并携带真实 loadedEntry 溯源——仅在 SDK 18.3 adapter 路由上取证；不替换运行中宿主的缓存注册，其指引不再承诺 reload 式替换。
