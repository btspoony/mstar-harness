Impact

Every issue row and detail header renders severity as a 24px pastel pill. At a 13px row height the pill dominates the title, and pale backgrounds make critical and low read equally loud. Rank is carried by colour alone, so the list cannot be scanned by weight, and forced-colors mode loses the signal entirely.

Acceptance

Never colour a filled background for status. Dot is 6px on rows, 5px in the narrow sidebar. The literal enum text is always present, so forced-colors and greyscale keep the meaning.

Density rules

  • Base copy is 13/20. 14 is the only emphasis step above it; 16 is a screen title, 20 a page title.
  • Table rows are 32px; dense side lists 24px. No row grows for a badge — put metadata on a second line of the same cell.
  • Panel padding is 12px; panel gaps are 12px vertically, 16px horizontally.
  • Identifiers and timestamps use 11–12px mono; prose never goes below 13px.
  • Every table has a fixed layout with explicit column widths; the title column absorbs the slack.
  • Paths and untrusted text wrap or truncate with a title attribute — never squeeze a neighbouring column.
  • Overview answers “state now” inside 864px of content height at a 1440px viewport.

Container-width layout rules

@container pane — one named container, not the viewport

Every page body and every dsh pane declares container: pane / inline-size. Components reflow by the width they are given, so the same screen serves a 1440px dashboard, a 720px half-width dsh column and a 400px dragged column — no second implementation and no viewport media query in product layout.

< 620px--ms-reflow-tableTables keep two columns: the primary cell on line 1, its secondary facts as inline meta on line 2. Filters wrap to full-width fields. The plan board becomes a grouped list. Fields collapse to one column.
< 480px--ms-reflow-stackThe pane nav wraps to a second row, panel heads stack, milestone ids are dropped, the residual grid becomes one column.

Floors, stated rather than hidden: a table needs 300px of container to stay a table (below that it scrolls inside its own labelled container, never the page); the chart draws from 220px and is omitted below it while its table alternative remains; the pane is designed for 400–1200px, and the host opens fullscreen below a 768px viewport.

  • Table collapse is driven by one attribute on the table (data-narrow-cols="2"), never by per-cell classes: the header and body cells beyond that index drop together.
  • A collapsed row's meta line is derived from the row's own cells at runtime, so every fact has exactly one source.
  • A truncated cell always exposes its full text through a title attribute; truncation is never the only way to read a value.

How the two hosts consume this

Standalone dashboard

Light only today. The five destinations, the nav, tables and detail views are unchanged. `--ms-*` tokens resolve to the light column; the language switch and dark palette are adopted with the shared package.

dsh host

Same components, host chrome. --ms-* resolve through --dsw-* aliases, so the surface follows the host theme and locale. The right sidebar is a half-width column carrying the whole product — session focus, the five destinations and their detail views — and the main area carries the same five. No plugin titlebar: the pane starts at the host's tab strip.

One implementation

Components are host-agnostic: they read `--ms-*` and receive locale, theme and DTOs from a provider. No host-specific markup, no duplicated screen.

Dark is a designed palette, not inverted light: surfaces lift by ~4% per layer and the accent/success/warning/danger hues are re-tuned for contrast on dark.
