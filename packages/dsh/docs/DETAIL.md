Morning Star Harness gives a dsh session a delivery process instead of a prompt: the PM skill writes the plan, independent QC seats and reviewers check it, the executor implements on a feature branch, and PM Acceptance maps every criterion to evidence before the delivery is merge-ready. The plugin keeps that record in the session — a model-visible `mstar-engine` row at `agent/pre-step` plus three native gates on tool calls — and in the right sidebar, where the Morning Star Workflow panel lists open items, issue flow and iteration progress from the same workspace state the CLI writes.
