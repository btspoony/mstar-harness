The plugin makes the workspace harness visible and enforcing inside a dsh session. A model-visible `mstar-engine` row is appended at `agent/pre-step` (engine status, iteration phase gate and a workspace digest), three native tools carry the gates the shared MCP connection cannot provide (`mstar_plan_bind` binds the coordinator plan and writes this session's `executionBinding` slot, `mstar_audit_validate` runs the `mstar-audit` Hard Rule 4 credential scan and reports findings by line and type only, and `mstar_execution_clear` clears the caller's own binding), and the Morning Star Workflow right-sidebar panel reads and writes the same state over `/api/mstar/*`.
